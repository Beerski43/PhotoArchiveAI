- **Store: MSIX に包めば出せる**（Store が署名する）。データの置き場所を書き込める場所へ。PySide6 の LGPL を MSIX でどう満たすかは未確認
- Windows の実機では動かしていない。法的な判断ではない
**次は利用者の判断**（商用にするか・ArcFace と MUSIQ/NIMA をどうするか。記録の §4）。それまで 7 は着手しない。順序の次は 4.12（#121・着手は指示待ち）。
