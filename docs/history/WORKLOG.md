- **顔への操作を右クリックのメニューと打鍵へ寄せた。** `1`〜`9` で人物に割り当て、
  `C`/`U`/`N`/`X`/`G`/`Z`。ボタンは置かない（表示ごとに増えるため）
- **年齢を3か所に出した。** 割り当てメニューの人物名（`2 ひより（7歳）`・
  誕生前の写真があれば `⚠`）、プレビューの全員ぶん、サムネイル
- **左の一覧に残件数**（`db.face_counts` が1回の問い合わせで数える）
- **並びを選べるようにした**（自動割当の表示は**確信度の低い順**が既定）
- **取説を全面改訂**（[../operation/GUI_USAGE.md](../operation/GUI_USAGE.md)）

### なぜ

**手作業の量が精度の上限。** 他人の顔の 99.1% が家族の写真に混ざっていて
（2026-10-08 実測）、まとめて消せない。**1件あたりの手数を減らすしかない。**
別ウィンドウの開き直しと、「人物を選ぶ→割り当てる」の往復が、そのまま手数だった。

### 本筋の外だが直したもの

**`db.face_ids` が撮影年月の引数を受け取っていなかった。** 年月や「撮影日時
なしのみ」で絞った状態で行事の「まとめて…」を押すと `TypeError` で落ちる
（PR #64 で月の絞り込みを足したときの通し忘れ）。直したうえで、
**一覧・件数・まとめて処理が同じ絞り込みを受け取ること**をテストで見張るようにした。

「この人物ではない」の一覧を、専用の読み出しからふつうの絞り込みへ移した
（`db._face_filter` の `rejected_for_person`）。**撮影年月・行事・年齢・ページャが
効くようになった**（以前は効かなかった）。`rejected_face_ids_for_person` は削除。
