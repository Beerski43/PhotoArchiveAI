## GPU の実測（2026-10-11）

- GPU: GTX 670（Kepler・VRAM 2GB・ドライバ 470.256.02）。CPU: i7-3770K（8 スレッド・AVX2 なし）・メモリ 23GB
- CUDA 11 以降は Kepler（sm_30）を切っているので、`onnxruntime-gpu` も PyTorch の CUDA 版も動かない
- OpenCL（`cv2.dnn`・OpenCV 4.11）で `models/w600k_r50.onnx` を 8 枚ずつ流した: **CPU の onnxruntime 117ms/枚、OpenCL 391ms/枚、OpenCL FP16 272ms/枚**
- 測り方: `onnxruntime.InferenceSession(..., providers=["CPUExecutionProvider"])` と `cv2.dnn.readNetFromONNX` + `setPreferableTarget(DNN_TARGET_OPENCL / _FP16)` に乱数の (8,3,112,112) を3回流して平均（スクリプトはリポジトリに入れていない）
- 結論: 推論は CPU の ONNX Runtime に揃える。新しい GPU を足したら #8 で `onnxruntime-gpu` に差し替える
