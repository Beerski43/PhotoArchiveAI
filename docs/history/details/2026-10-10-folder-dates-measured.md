### 日まで主張しない理由

**日付入りのフォルダ名は行事の初日で、撮影日ではない。** 日までだと不一致の大半が「初日より後」:
`101201${EVENT}` は +1〜5日（入院中）、`131009${PERSON_5}誕生` も +1〜6日、`190112スノーアドベンチャー` は +1日。
`061231USJ` は元日の 0時台に撮っている。

### 日付の無いサブフォルダを年に戻す理由

`071222Wedding/式前/衣装合わせ`（−70日）、`110416${EVENT}/式場/前撮り`（−52日）のように、
**行事の下の日付の無いフォルダには行事より前の写真が入っている。** 親の月を受け継ぐと 192 件が
食い違う（469 → 277）。代わりに年だけ受け継ぐので、対象のうち 111 件が月から年へ粗くなる。

## 3. `match` への効き方（実データの複製・2026-10-10）

複製を `migrate`（版6。5.7秒・バックアップ込み。Media 70,269 件に区間が入り、顔 58,606 件は減らない）
したうえで、区間を空にした複製（＝これまでの挙動）と比べた。

| 案 | 自動割り当て | 差 |
|---|---|---|
| これまで（推測を使わない） | 9,912 | — |
| B: 誕生前の除外と、手本の年齢（閾値の上限）に使う | 9,841 | 外れる 125（${PERSON_4} 36・${PERSON_5} 89）／付く 54 |
| **C: 誕生前の除外にだけ使う（採用）** | **9,914** | 付く 2（${PERSON_3}） |

- B では日付の無かった手本 10,753 件中 661 件に年齢が付く。多くは年上で上限が緩み（0.40 → 0.45）、
  8歳以下と分かったものは締まる（0.40 → 0.35）
- **B で外れた 125 件は、サムネイルを並べて見ると大半が正しい割り当てだった**（6〜10歳ごろの${PERSON_4}・
  ${PERSON_5}。眼鏡・マスク）。付いた 54 件は年上の子ども・十代でおおむね妥当（成人男性らしい顔と
  加工写真が1件ずつ）
- **利用者が C を選んだ**（AskUserQuestion）。手本の年齢は EXIF だけで決める（`db._teacher_age`）
- 実装後の複製でも C と完全に一致した（9,914 件・差 0 件）
- 規則の版は `aligned-age/3`（`select` が古い判定の残りを知らせる）

## 4. 利用者が決めたこと

| 論点 | 決定 |
|---|---|
| 主張する精度 | **月まで**（日付の無いサブフォルダは年だけ受け継ぐ） |
| Issue の完了条件「EXIF と照合して誤り0件」 | **不一致を全件分類して記録する。** 解釈の誤りは 0 件にする |
| 効かせる範囲 | **表示・絞り込み・`match` のすべて** → `match` は測ったうえで**誕生前の除外だけ**（上の §3） |

## 5. やっていないこと

- **行事（フォルダ×日）の束ねは変わらない。** 月までしか主張しないので日が決まらない
- **ファイル名の日時は読んでいない**（`20130816173822.JPG`・`IMG20230819173023.jpg`・
  LINE の保存名 `1399605778477.jpg`（ミリ秒の UNIX 時刻）など）。EXIF の無い写真の多くは
  LINE などで受け取ったもので、ファイル名の時刻は**受け取った・保存した時刻**であって撮影日ではない
  ことがある。Issue #65 の範囲外。やるなら同じ照合で確かめてから
