## 踏んだ落とし穴（繰り返さないために）

- **このリポジトリには本物の `config/app_settings.yml` がある。** 設定を書くテストは、探す場所（`PHOTOARCHIVE_CONFIG`・カレント・`config.REPO_ROOT`）を全部 `tmp_path` に向けること（`tests/test_gui_settings.py` の `isolated_config`）。カレントだけ移しても、リポジトリ直下の設定が拾われて書かれる
- **相対の root の起点は `config.resolve_source_root` だけで決める。** 同じことを2か所に書いたら起点が食い違った（指摘1）
- 再現スクリプトで窓の `save()` を何度も呼ぶと、再現用の設定ファイルそのものが書き換わる。続けて別の指摘を確かめるときは、ファイルを作り直してから流す
- `QDialog.resize(w, 0)` で高さを 0 にすると、一覧が下の注記に重なる。`setMinimumWidth` ＋ `adjustSize` にする
