## 3. 他人誤認率 — ここで既定値が覆った

同じ写真に写る2つの顔を「別人」とみなして測る。**dlib の 0.4 を選んだときと
同じ数え方**（仕様書 §8.3）。実データ全件から **37,933 組**。

| 閾値 | 他人誤認率 |
|---|---|
| 0.35 | 0.42% |
| 0.40 | 0.61% |
| 0.42 | 0.73% |
| **0.45** | **1.06%** |
| 0.48 | 1.48% |
| 0.50 | 1.92% |
| 0.55 | 3.47% |
| **0.60（当初の既定）** | **5.64%** |

**dlib の既定 0.40 での同じ数字は 0.5〜1.0%。**

### 当初 0.60 を選んだのが誤りだった

**手本どうしのペアだけで閾値を選んでいた。** 「行事をまたぐ別人のペアの誤りが
1%以下になる最大の閾値」として 0.603 を採ったが、**手本は家族5人しかいないので、
数えていたのは家族内の取り違えだけ。** 他人が紛れ込む誤りは1件も入っていなかった。

`evaluate` の誤りが 0.60 でも 1.6% と低く見えるのも同じ理由
（家族5人の中だけを数えている）。

**未割当 58,212 件の大半は他人である**（結婚式フォルダの 1,357 件など）。
本番で実害が出るのは**他人が家族に割り当てられること**で、そこを測れていなかった。

**教訓: 閾値は「本番で解く問題」と同じ母集団で測る。**

### 0.45 を選んだ理由

| | dlib 0.4 | ArcFace 0.60 | **ArcFace 0.45** |
|---|---|---|---|
| `evaluate` 正解 | 26.9% | 88.9% | **78.6%** |
| `evaluate` の誤り | 2.6% | 1.6% | **0.0%** |
| **他人誤認率** | 0.5〜1.0% | **5.64%** | **1.06%** |

正解を 88.9% → 78.6% と譲る代わりに、**他人誤認を 5.64% → 1.06% に下げた。**
「誤って紐づけるより取りこぼす側に倒す」という方針（§8.3）に沿う。

**0.45 は dlib のどの指標も上回る。**

## 4. この測定の限界（割り引いて読むところ）

- **「同じ写真なら別人」は仮定。** 鏡・ポスター・壁の写真立て・顔でないものの
  誤検出で外れる。外れたぶんは誤りに数えられるので、**他人誤認率は実際より
  高めに出る**（両方が手本で同じ人物のペアは除いてある。実データで1組あった）
- **`evaluate` の正解は実運用より甘い。** 連写のように似た手本が別のファイルに
  あると当てやすい（`evaluate` 自身が出力で警告する）
- **手本126件・人物5名。** 誤差は小さくない。とくに人物ごとの内訳は
  1件の増減で数ポイント動く
- **ペアの率は顔1件あたりの率ではない。** `match` は手本すべてとの最小距離を
  採るので、誰か1人に似ていれば割り当てられる。「他人の1.06%しか間違わない」と
  読むと過小評価になる
- **整列できなかった 8,157 件（13.9%）の精度は落ちている。** その分がどれだけ
  成績を押し下げているかは、分けて測っていない
