## 踏んだ落とし穴

- **「1人目から足しても並びは変わらない」は誤りだった。** 人数に数えるのは「はっきり写った」家族だけなので、はっきり写った家族が1人もいない写真（実データで家族の写った写真 16,457 枚のうち 2,715 枚）は 20 下がる。回帰テスト（`test_expression.py`）が落ちて気づいた。実データの複製では出力は入れ替わらなかった。**点の式を変えたら、定数のずれに見えても条件つきの項が無いか見る**
- `photoarchive assess` の実行中は、本体の checkout のコードを書き換えない（`pip install -e .` なので、遅れて import されるモジュールが変わりうる）。ワークツリーで作業し、`PYTHONPATH=<ワークツリー>/src` でテストと回帰テストを流した（CLAUDE.md §8 にある）
- 実行中の DB の複製は、`sqlite3.connect('file:...?mode=ro', uri=True).backup(...)` で取れる（WAL なので書き手を止めない）
