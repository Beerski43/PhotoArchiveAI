## 踏んだ落とし穴

- **Python に渡すヒアドキュメントを `<<EOF`（引用なし）で書くと、本文のバッククォートがシェルのコマンド置換になる**（PR 本文の書き換えで `tests/...: 許可がありません` と出て置換が外れた）。`<<'EOF'` にし、値は環境変数で渡す
- `jobs.Job` の子は **daemon にしない**（daemon の子は `scan` のワーカーを作れない）。`with ProcessPoolExecutor` のまま例外で抜けると残りを全件処理するまで待つので、`shutdown(cancel_futures=True)` してから抜ける
- 1つのトランザクションにした書き込みは、テストで「別の接続でロックを取る」では落とせない（こちらがロックを握っている）。落としたい関数で `OperationalError` を投げる
- 回帰テストの所要時間が一度 109 秒になったが PC の負荷のせい（直後は 43 秒）
- `gh pr edit` は使えない。PR 本文は `gh api -X PATCH repos/:owner/:repo/pulls/<N> -F body=@<ファイル>`
