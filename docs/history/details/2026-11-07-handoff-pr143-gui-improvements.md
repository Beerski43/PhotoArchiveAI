## 踏んだ落とし穴（繰り返さないために）

- **QSS をかけたあとに、窓を開いたまま `setStyle` を呼ぶと Qt ごと落ちる。** CLAUDE.md §8 に書いた
- **回帰テストが「遅い」のではなく止まっていた、が2回あった。** 原因はどちらも別で、`-o faulthandler_timeout=60` を付けて `timeout` の下で流すと止まった場所が出る
  1. 先に流れたテストの窓が残ったまま QSS をかけると、全部の部品を描き直して 1 回に 90 秒以上かかる（`tests/test_gui_theme.py` の `themed` が片付ける。実物の窓1枚なら 0.24 秒）
  2. 年齢の揃わない顔を選ぶ既存テストが、本物の `FaceAgesDialog` を開いて待ち続けた（`tests/conftest.py` の `face_ages_dialog_does_not_block` が、固まらずに失敗させる）
- **設定ファイルに書く操作を描画の確かめで呼ぶと、カレントの `config/` に書く。** 実際に worktree へ `app_settings.yml` を作って消した。本体の checkout で流していたら実データの設定を書き換えていた。スクリプトでも `os.chdir` で一時フォルダへ移す（CLAUDE.md §8）
- **コメントや PR の本文に GitHub の URL を貼ると、アカウント名が公開しない語に当たる。** 投稿前に `python scripts/check_private_terms.py --message <ファイル>` を流す。コメントは番号（`issuecomment-…`）で書く
- `gh pr edit` は Projects (classic) の廃止告知で落ちる。`gh api -X PATCH repos/:owner/:repo/pulls/143 -F body=@file` を使う
- worktree のセッションでは、複合コマンド・`source`・`$(...)`・`xargs` を含むシェルが拒まれることがある。Python のスクリプトに分けるか、1行ずつ流す。`pkill -f` は自分のシェルに当たる
