# GUI利用手順

PhotoArchiveAIのGUIでは、人物情報の管理と、`photoarchive scan` が検出した顔の人物への割り当てを行えます。

ここで割り当てた顔が、`photoarchive match` による自動紐づけの手本になります。

## 起動前の準備

GUIを起動する前に、次を完了してください。

1. UbuntuのGUI関連ライブラリをインストールする
2. Python依存ライブラリをインストールする
3. SQLiteデータベースを初期化する
4. `photoarchive scan` を実行して、写真の登録と顔の検出を済ませておく

GUIは検出済みの顔を割り当てる画面です。`scan` を実行していないと、割り当てる顔が1件も表示されません。

インストール方法は [README.md](../../README.md#インストール) を参照してください。

GUIはX11またはWaylandの表示セッションが必要です。SSHなどのリモート環境から起動する場合は、X11転送やWaylandの接続設定も必要になります。

## 起動

仮想環境を有効にして、データベースを指定します。

```bash
source .venv/bin/activate
photoarchive-gui --db data/photoarchive.db
```

別のデータベースを使う場合は、そのパスを `--db` に指定します。

```bash
photoarchive-gui --db /path/to/photoarchive.db
```

## データベースの移行を求められたら

アプリケーションを新しくしたあと、起動すると次の確認が出ることがあります。

```
データベースの移行が必要です

  移行対象: data/photoarchive.db
    Media 70,297 件 / Person 5 件 は保持します。
    顔データ 58,606 件はそのまま残ります（列を追加するだけの移行です）。

  実行する前に、自動でバックアップを取ります。

                      [ 移行を実行 ]  [ 終了 ]
```

`移行を実行` を押すと、その場で移行してそのまま画面が開きます。**端末で
`photoarchive migrate` を実行する必要はありません。**

- **何が残るかは、この画面に出ます。** 「そのまま残ります」と書かれていれば、
  列を足すだけの移行で、顔もスキャンの結果も消えません
- **実行する前に、自動でバックアップを取ります**（`<データベース名>.bak-<日時>`）。
  データベースと同じ大きさのファイルができるので、空き容量を確かめてください
- `終了` を選ぶとアプリケーションは終了し、**データベースには一切触れません**
- 失敗した場合は理由が出て、画面は開きません。バックアップは残っています

## 画面構成

メイン画面は左右に分かれています。

```
┌──────────────┬──────────────────────────────┬────────────┐
│ 人物一覧      │ 顔のサムネイル一覧              │ 拡大プレビュー│
│ [追加][編集]  │                              │             │
│ [削除]       │ [< 前] 3 / 310 ページ [次 >]   │             │
│ [割り当て済み] │                              │             │
│ 人物詳細      │ [選択した顔を割り当て][除外]     │             │
│              │ 行事: すべての行事              │             │
│              │ [行事を選ぶ][解除][束ねる][一括] │             │
└──────────────┴──────────────────────────────┴────────────┘
```

左側（人物）

- `人物追加`: 新しい人物を登録
- `編集`: 選択中の人物情報を変更
- `削除`: 選択中の人物を削除（顔は消えず、未割当に戻ります）
- `割り当て済みを確認`: 選択中の人物に割り当てた顔を表示
- 人物一覧: 登録済み人物を表示。**ドラッグで並べ替えられます**
- 人物詳細: 名前、続柄、誕生日、メモ、手動割当と自動割当の件数

右側（顔）

- 表示の切り替え: `未割当` / `自動割当` / `除外済み`
- 顔のサムネイル一覧: 1ページ200件。**撮影日時の新しい順**に並びます
- `< 前` / `次 >`: ページの移動
- `選択した顔を割り当て`: 選択中の人物へまとめて割り当て
- `この顔を除外`: 誰でもない顔を一覧から外す
- `未割当に戻す`: 除外や自動割当を取り消して未割当へ戻す
  （`未割当` を表示しているときは押せません）
- 拡大プレビュー: 選択中の顔を、元の写真から切り出し直して表示
- プレビューの下: その写真の**撮影日時**と、**保存されているフォルダ**、ファイル名、
  **選択中の人物がその写真で何歳か**
- `行事を選ぶ`: 一覧を**行事（フォルダ×日）**に絞る
- `解除`: 行事の絞り込みをやめる
- `この行事の顔を束ねる`: 似た顔を束ねて、束ごとにまとめて処理する
- 一番右のボタン: 行事まるごとの処理。表示に応じて
  `未割当をすべて除外` / `除外をすべて取り消す` / `自動割当をすべて取り消す`
  に変わります（**行事を選ぶまで押せません**）

## 人物の並び順を変える

**人物一覧はドラッグで並べ替えられます。** よく割り当てる人物を上に置いて
おくと、毎回探さずに済みます。

1. 人物一覧で、動かしたい人物を掴む
2. 置きたい位置まで動かして離す

**離した時点で保存されます**（保存ボタンはありません）。次に起動したときも
同じ順で出ます。

- **追加した人物は、いちばん下に入ります。** 並べ替えた結果を崩さないためです
- **並べ替えるまでは登録した順**に並びます。ただし**この機能より前から登録して
  あった人物**（データベースを移行した時点で居た人物）は、最初は**名前順**です

## 人物を追加する

1. `人物追加` を押す
2. 名前を入力する
3. 必要に応じて続柄、誕生日、メモを入力する
4. `OK` を押す

名前は必須です。名前が空の場合は登録できません。

## 人物情報を編集する

1. 人物一覧から対象の人物を選択する
2. `編集` を押す
3. 名前、続柄、誕生日、メモを変更する
4. `OK` を押す

名前を空にすることはできません。

## 誕生日を登録する（年齢の入力が楽になります）

人物に誕生日を入れておくと、**写真の撮影日時から撮影時の年齢を機械が出します。**
顔を割り当てるたびに暗算する必要がなくなります。

`人物追加` / `編集` の `誕生日` は、**年・月・日が別々の入力欄**です。

```
誕生日  [2011]年 [5]月 [3]日
```

- **3つとも空（`--`）なら「未設定」**です。入れなくても、これまで通り年齢を
  手で入力できます
- **キーボードから直接打てます。** 欄には `--` が入っていますが、触れば全選択
  されるので、そのまま数字を打てば置き換わります（▲▼でも変えられます）
- **年・月・日はすべて必要です。** 一部だけだと警告が出ます。月日が分からないと
  年齢を出せないためです
- 2月30日のような**存在しない日付**も警告が出ます
- 警告が出たときは、**その追加・編集は行われません。** 入力し直してください

登録した誕生日は人物詳細に出ます。年齢が出ないときは、ここが `未設定` になって
いないかを確かめてください。**`OK` を押した時点で、プレビューの年齢の行は
すぐ出ます**（人物を選び直す必要はありません）。

誕生日は**年齢を計算するためだけ**に使います。`Face.age` に何を入れるかを決めるのは
利用者です（機械が勝手に保存することはありません）。

## 顔を人物へ割り当てる

1. 人物一覧から割り当て先の人物を選択する
2. 表示の切り替えが `未割当` になっていることを確認する
3. サムネイル一覧から、その人物の顔をクリックして選ぶ
   - `Ctrl` を押しながらクリックすると複数選べます
   - `Shift` を押しながらクリックすると範囲で選べます
4. 顔を選ぶと右側に拡大表示されるので、本人か確認する
5. `選択した顔を割り当て` を押す
6. 撮影時の年齢を入力する（未指定も可能）

**年齢はキーボードから直接打てます。** 入力欄は「未設定」が選ばれた状態で開くので、
そのまま数字を打てば置き換わります（▲▼でも変えられます）。何も打たなければ
「未設定」のままです。**0歳と「未設定」は別の状態**として保存されます。

**複数の顔をまとめて選んだときは、入力した年齢が全件に入ります。** 件数と、
選んだ顔の撮影日時の範囲がダイアログに出ます。撮影日時がまたがっている場合は
そう表示されるので、**年の違う写真をまたいで選んでいないか**を確かめてください
（プレビューに出ているのは、最後に選んだ1枚の撮影日時です）。

**時間のかかる操作では、カーソルが砂時計になります。** 押せたかどうかが
分かるようにするためです。顔を選ぶと元の写真を読み直すので、写真の大きさに
よっては少し待ちます。

**複数枚をまとめて処理するときは、進み具合が件数で出ます**（`120 / 200 件`）。
すぐ終わる場合は窓を出しません。**途中で止めることはできません**
（半分だけ適用された状態になるため）。

**登録が済むと、顔写真に重ねて `完了` と出て、写真が薄くなります。**
顔は一覧から消えるのにプレビューには残るので、そのままだと「まだ選んでいる」
ように見えて、**同じ顔をもう一度登録してしまいます。** 次の顔を選べば元に
戻ります。除外したときも同じように出ます。

**年齢はプレビューの下の撮影日時から計算します。**

```
撮影日時: 2017-12-16 18:46:32
フォルダ: 2017/171216クリスマスパーティー
ファイル: 20171216184632.JPG
なつ: 6歳
```

最後の行は、**選択中の人物がこの写真で何歳か**です（誕生日を登録している場合）。
人物を選び直すと、この行も切り替わります。

- 人物を選んでいない、誕生日が未設定、撮影日時が無い、のいずれかなら
  **この行は出ません**
- 撮影日が誕生日より前なら **`誕生前`** と出ます。行が消えないので、
  **人物を選び間違えていないか、日付が間違っていないか**に気づけます

**誕生日を登録していると、年齢の入力欄に計算した年齢が最初から入ります。**
そのままでよければ `OK` を押すだけです。違うと思えば打ち替えてください
（`OK` を押すまで保存されません）。

**選んだ顔が別々の年齢になる場合は、初期値を入れません**（`未設定` で開きます）。
1回の入力が選択中の全件に入るため、片方の年齢を入れると、もう一方に間違った
年齢が黙って入ってしまうからです。

**撮影日時の分からない顔が1枚でも混ざっている場合も、初期値を入れません。**
その顔が何歳のときのものか決めようがないためです。ダイアログに
`うち N 件は撮影日時が分かりません。` と出るので、**選び直すか、年齢を手で
入れてください。**

写真に EXIF が無い場合は `撮影日時: 不明（EXIFなし）` と出て、代わりに
ファイルの日時が並びます。**ファイルの日時は撮影日時ではありません**
（コピーすると変わります）。フォルダ名に日付が入っていることが多いので、
そちらも手がかりにしてください。

フォルダは設定の `source_root` からの相対で表示します。`source_root` の外に
あるメディアは、絶対パスのまま出ます。`source_root` の直下にある写真は
`（source_root 直下）` と出ます。

設定の `source_root` が相対パスのときは、**設定ファイルの置き場所が起点**です。
どのディレクトリから起動しても同じ表示になります。

**一覧は撮影日時の新しい順です。** 同じ日に撮った写真がひとかたまりで出るので、
行事ごとにまとめて選んで一度に割り当てられます。撮影年をまたがないため、
**年齢の初期値もそのまま使えます**（誕生日を登録している場合）。

**撮影日時を持っていない写真は、いちばん後ろのページに集まります。** EXIF の
無い写真（実データの約16%）と、カメラが壊れた日時を書いた写真がここに入ります。
判別しにくいものが多いので、**前の方のページから進めてください。**

`photoarchive match` の精度は、この手作業の量で決まります。人物あたり20〜50枚を目安に、正面、横向き、眼鏡の有無、年齢の違う顔を割り当てておくと、自動紐づけの精度が上がります。

顔の切り出しや特徴量は `scan` の時点で作成済みです。GUIが元の写真ファイルを変更することはありません。

## 撮影年月で絞る（家族以外をまとめて外すとき）

未割当の一覧の上で、**いつからいつまでに撮られた写真の顔だけ**を表示できます。

```
[未割当 ▼]  撮影 [2015-07 ▼] 〜 [2015-09 ▼]  □ 撮影日時なしのみ
```

**両端を含みます。** 片方を `指定なし` にすれば「2015-08 以降すべて」「2015-08 以前
すべて」もできます。上下を逆にすると、もう片方が自動で押し戻されます。

**家族の写っていない写真は時期でまとまっています。** 結婚式や旅行先で写った他人は、
その行事の期間に固まっているので、**その月だけを開いて `この顔を除外` でまとめて
外せます。**

- 並ぶのは**顔のある写真の月だけ**です（選んでも1件も出ない月は出しません）
- `撮影日時なしのみ` にチェックを入れると、**EXIF に日時の無い写真と、カメラが
  壊れた日時を書いた写真**がまとまって出ます。**範囲とは併用できません**
  （読めない日付はどの範囲にも入らないため）。該当が1件も無ければ出てきません
- 両方を `指定なし` に戻せば絞り込みは解除されます

**この絞り込みは「種別」と併用できます。** `自動割当` × `2015-08` のように、
その月の自動割り当てだけを見直すこともできます。

## 行事ごとにまとめて片付ける（おすすめ）

**1件ずつ選ぶより、こちらのほうが速く終わります。** 未割当は 5万件以上あるので、
同じ行事（同じフォルダ・同じ日）の似た顔をまとめて処理します。

### 1. 行事を選ぶ

1. `行事を選ぶ` を押す
2. 一覧は**未割当の多い順**に並んでいます。上から片付けると効き目が大きいです
3. 絞り込み欄に行事名や日付を打つと探せます（例: `結婚式` / `2011-04`）
4. 選んで `OK`（行をダブルクリックでも開きます）

撮影日時が読めない写真は「**（撮影日時不明）**」としてフォルダごとにまとまります。

### 2. 束ねて、まとめて割り当てる／除外する

1. `この行事の顔を束ねる` を押す
2. 左に束の一覧、右にその束の顔が出ます
   - `束 1 — 12 件（手本: なつ）` のように、**その束に手本が混ざっていれば
     誰の束かが分かります**
   - `済` と付いた束は、もう判断の済んだ顔だけです
3. 右の顔を見て、全員同じ人なら
   - `人物` を選んで `この束をまとめて割り当て`（年齢の入力は1件ずつと同じ）
   - 他人の束なら `この束をまとめて除外`
4. **別人が混ざっていたら `この束を割る`。** もっと厳しい近さで割り直します。
   何度でも押せます

**手本（自分で割り当てた顔）は、まとめて押しても絶対に動きません。**
ボタンの下に「押すと、この束の未判断 N 件に効きます」と出るので、
何件動くかを確かめてから押してください。

**割り当て先の人物に出ないことがあります。** その日より後に生まれた人物は、
選べないように外してあります（誕生日を登録している場合）。

### 3. 行事まるごと処理する

結婚式や学校行事のように**ほとんど他人**の行事は、束ねずに
`この行事の未割当をすべて除外` で片付けられます。ページをまたいで効きます。
手動で割り当てた顔は触りません。やり直したいときは、表示を `除外済み` にして
`この行事の除外をすべて取り消す` を押します。

## 除外を取り消す（未割当に戻す）

間違えて除外した顔や、判断を保留したい顔は、**未割当に戻せます。**

1. 表示の切り替えを `除外済み` にする
2. 戻したい顔を選ぶ
3. `未割当に戻す` を押す

`未割当` を表示しているときは、戻す先が無いのでこのボタンは押せません。

**`自動割当` を表示しているときにも使えます。** 自動で付いた紐づけを外して、
未割当に戻せます（`割り当て済みを確認` の `割り当てを解除` と同じことを、
人物を選ばずにできます）。

## 誰でもない顔を除外する

背景に写り込んだ他人や、顔ではないものを誤検出した場合は、その顔を選んで `この顔を除外` を押します。除外した顔は未割当の一覧から外れ、自動紐づけの対象にもなりません。

## 割り当て済みの顔を確認・訂正する

1. 人物一覧から対象の人物を選択する
2. `割り当て済みを確認` を押す
3. `種別` で絞る（`すべて` / `確定済みのみ` / `自動のみ` / `この人物ではない`）
4. 年齢の下限と上限を指定する（`指定なし` にすると絞りません）
5. サムネイル一覧から顔を選ぶ

### 「違う」と思った顔は、解除ではなく `この人物ではない` を押す

**除外は2種類あります。**

| ボタン | 意味 | ほかの人物には |
|---|---|---|
| `この人物ではない` | **その人物ではない** | **自動で付きえます** |
| `誰でもない顔` | 家族の誰でもない | 付きません |

**`割り当てを解除` では判断が残りません。** `photoarchive match` は手本と閾値だけで
結果を決めるので、未割当に戻しただけだと**流すたびに同じ顔が同じ人物に戻ります。**
実際、ひよりの自動割り当てを見直して解除した **1,785 件**がこの状態でした（2026-10-08）。

**兄弟の赤ん坊の顔は互いによく似ています。** 「ひよりではないが、弟かもしれない」顔には
`この人物ではない` を使ってください。`誰でもない顔` にすると、弟にも付かなくなります。

**`種別` で `自動のみ` を選ぶと、自動で割り当てられた顔だけが並びます。**
自動紐づけの結果を見直すときはここを使ってください。逆に `確定済みのみ` を選べば、
手本として使われている顔だけを見直せます。

**年齢の絞り込みは、画面に出ている年齢と同じものを見ます。** `Face.age`（確定値）が
入っていればその値で、入っていなければ**誕生日と撮影日時から計算した年齢**で絞ります。
`match` は年齢を書かないので、**この計算が無いと自動割り当ての顔は1件も年齢で絞れません。**

**`年齢不明も含める` は、年齢をどうしても出せない顔の扱いです。** 誕生日が未登録か、
写真に撮影日時が無い顔が該当します。**既定は「含めない」**で、「7〜9歳」と指定したときに
年齢の分からない顔が混ざらないようにしています。見たいときはチェックを入れるか、
`指定なし` に戻してください。

**`0` は 0歳の意味です。**「指定なし」は `0` の1つ下（`--`）にあります。

この画面も1ページ200件です。`< 前` / `次 >` でページを移動できます。種別や年齢で絞り込むと1ページ目に戻ります。

**並びは年齢の若い順です。** 成長の順に出るので、**年齢の入れ間違いや、別人が
混ざっていること**に気づきやすくなります。**年齢が未設定の顔は、いちばん後ろに
まとまります**ので、そこから埋めていくとよいです。

選んだ顔に対して、次の操作ができます。

- `選択した顔を確定`: 自動で割り当てられた顔を「手動割り当て」に昇格します。昇格した顔は次回の `photoarchive match` の手本に加わるため、繰り返すほど精度が上がります
  - **自動割り当ての顔を選んでいるときだけ押せます。** すでに確定済みの顔に押しても意味のある変化が起きないためです（押せない理由はボタンにマウスを乗せると出ます）
  - **中身を見てから押してください。** 確定した顔は `match` の判断の根拠になるので、**間違ったまま確定すると、次回以降その誤りが根拠になって広がります**
- `割り当てを解除`: 未割当に戻します。**判断は残りません。** `photoarchive match` を流すと、同じ顔がまた同じ人物に付きます
- **`この人物ではない`**: **その人物ではない、と記録します。** `match` を流し直しても、その人物には二度と自動で付きません。**ほかの人物には付きえます**（兄弟の顔など）
- **`誰でもない顔`**: 家族の誰でもない顔として除外します。**どの人物にも自動で付かなくなります。** 取り返しがつきにくいので確認が出ます
- `「この人物ではない」を取り消す`: 押し間違いを戻します。種別で `この人物ではない` を選ぶと一覧できます
  - **その一覧で `誰でもない顔` を押すと、その顔は一覧から消えます。** 除外した顔は
    どの人物にも付かなくなるので、「この人物ではない」の記録はもう効いていないためです
  - **記録自体は残っています。** あとで除外を取り消すと、また一覧に戻ります
- `年齢を設定`: 撮影時の年齢を後から設定します。`未設定` を選べば、一度入れた年齢を消せます。ここもキーボードから直接打てます。誕生日を登録していれば、ここでも計算した年齢が初期値に入ります

サムネイルには、自動割り当ての顔に `(自動 82)` のように確信度が表示されます。数値が低い顔から確認すると、誤りを見つけやすくなります。

**確信度には下限があり、0 にはなりません**（既定の閾値 0.45 では 55.0）。閾値より遠い顔はそもそも割り当てられないためです。**下限に近いほど怪しい**と読んでください。

### 撮影時の年齢が出ます

サムネイルには年齢も並びます。**自動割り当てが正しいかを見分けるのに、いちばん効く
手がかりです。**

| 表示 | 意味 |
|---|---|
| `7歳` | `年齢を設定` で入れた値。**人が確かめた年齢** |
| `(7歳)` | **誕生日と撮影日時から計算した年齢**（括弧つき） |
| `(誕生前)` | **撮影日がその人の誕生日より前。ほぼ確実に誤りです** |
| （何も出ない） | 誕生日が未登録か、写真に撮影日時が無い |

`match` は年齢を書かないので、自動で割り当てられた顔は年齢が未設定です。そのため
**括弧つきの計算値**が出ます。括弧の有無で「人が確かめた値かどうか」を見分けてください。
計算しただけの年齢がデータベースに書き込まれることはありません。

**年齢を出すには、人物に誕生日を登録しておく必要があります**（「誕生日を登録する」）。

## 自動紐づけの結果をまとめて取り消す

GUI で見直して自動紐づけの結果が信用できなかったときは、コマンドで取り消せます。

```bash
# 1人ぶんだけ
photoarchive unassign-auto --person ひより

# 全員ぶん
photoarchive unassign-auto
```

**手動で割り当てた顔（手本）・除外した顔・設定した年齢には触りません。**
手本を直してから `photoarchive match` を流し直せば付け直せます。

## 人物を削除する

1. 人物一覧から対象の人物を選択する
2. `削除` を押す
3. 確認ダイアログで `Yes` を押す

人物を削除しても、その人物に割り当てた顔は削除されません。未割当の状態に戻るので、別の人物へ割り当て直せます。この操作は元の写真ファイルには影響しません。

## 自動紐づけとの関係

GUIで顔を割り当てたあと、`photoarchive match` を実行すると、割り当て済みの顔を手本にして残りの顔が自動で紐づきます。

```bash
photoarchive match
```

- 手本になるのは **手動で割り当てた顔だけ** です。自動で割り当てられた顔は、`割り当て済みを確認` から「確定」しない限り手本になりません
- 似ている度合いが基準に届かない顔は、未割当のまま残ります。GUIで手作業を続けてから `match` を実行し直してください
- `match` は実行のたびに自動割り当てを付け直します。手動の割り当てには影響しません

十分な枚数を手作業で割り当ててあるなら、`match` を実行しなくても構いません。

## 終了

ウィンドウを閉じるとGUIを終了できます。
