# GUI利用手順（取扱説明書）

PhotoArchiveAI の GUI は、**人物の登録**と、`photoarchive scan` が検出した
**顔の人物への割り当て**を行う画面です。ここで割り当てた顔が
`photoarchive match` の**手本**になります。

**この画面の作りは「1件あたりの手数を減らす」ことだけを考えています。**
理由は実データで分かったことです。他人の顔の **99.1%** が家族の写真に混ざって
いて（2026-10-08 実測）、まとめて消せません。**手作業そのものは減らせないので、
1件を速くするしかない**という結論になりました。

## 起動前の準備

GUI を起動する前に、次を完了してください。

1. Ubuntu の GUI 関連ライブラリをインストールする
2. Python 依存ライブラリをインストールする
3. SQLite データベースを初期化する
4. `photoarchive scan` を実行して、写真の登録と顔の検出を済ませておく

GUI は**検出済みの顔を割り当てる画面**です。`scan` を実行していないと、
割り当てる顔が1件も表示されません。

インストール方法は [README.md](../../README.md#インストール) を参照してください。

GUI は X11 または Wayland の表示セッションが必要です。SSH などのリモート環境から
起動する場合は、X11 転送や Wayland の接続設定も必要になります。

## 起動

仮想環境を有効にして、データベースを指定します。

```bash
source .venv/bin/activate
photoarchive-gui --db data/photoarchive.db
```

`--db` を省くと `config/app_settings.yml` の `database_path` を使います。

**画面の明るさはメニューの `設定` → `表示モード`**（OS に合わせる／ライト／ダーク）で、すぐ切り替わります。次に起動したときも同じです（#18）。

DB の場所・写真の置き場所・出力先は、起動してから**メニューの `設定…`** でも直せます（[設定を直す](#設定を直す)）。

## データベースの移行を求められたら

アプリケーションを新しくしたあと、起動すると次の確認が出ることがあります。

```
データベースの移行が必要です

  移行対象: data/photoarchive.db
    Media 70,297 件 / Person 5 件 は保持します。
    顔データ 58,606 件はそのまま残ります（列を追加するだけの移行です）。

  実行する前に、自動でバックアップを取ります。

                      [ 移行を実行 ]  [ 終了 ]
```

`移行を実行` を押すと、その場で移行してそのまま画面が開きます。**端末で
`photoarchive migrate` を実行する必要はありません。**

- **何が残るかは、この画面に出ます。** 「そのまま残ります」と書かれていれば、
  列を足すだけの移行で、顔もスキャンの結果も消えません
- **実行する前に、自動でバックアップを取ります**（`<データベース名>.bak-<日時>`）。
  データベースと同じ大きさのファイルができるので、空き容量を確かめてください
- `終了` を選ぶとアプリケーションは終了し、**データベースには一切触れません**
- 失敗した場合は理由が出て、画面は開きません。バックアップは残っています

## 画面構成

起動すると**タブが2枚**あります。1枚目「顔の割り当て」が下の画面、2枚目「写真の選定」は [写真の選定タブ](#写真の選定タブselect-の調整) で説明します。ほかの処理は、窓の上の**メニューから別の窓で**動かします（#132）。

| メニュー | 項目 | 説明 |
|---|---|---|
| 取り込み | `取り込みウィザード…` | [取り込みウィザード](#取り込みウィザード) |
| 取り込み | `写真の良し悪しを測る（assess）…` | [写真の良し悪しを測る](#写真の良し悪しを測る) |
| 顔の割り当て | `自動割り当て（match）…` | [GUI から流す](#gui-から流すおすすめ) |
| 顔の割り当て | `自動割り当てを取り消す（unassign-auto）…` | [自動割り当てを取り消す](#自動割り当てを取り消す) |
| 顔の割り当て | `精度を測る（evaluate）…` | [精度を測る](#精度を測る) |
| 設定 | `設定…` | [設定を直す](#設定を直す) |

**`顔の割り当て` のメニューは、1枚目のタブを開いているときだけ選べます。** 裏で処理を流しているあいだは、`自動割り当て` と `取り消す` も押せません。

### 左: いま何を見ているか

**人物一覧の上に、3つの表示が並んでいます。** 左の一覧は「人物を選ぶ場所」では
なく「**何を見るかを選ぶ場所**」です。

| 左で選ぶもの | 右に出るもの |
|---|---|
| `未分類` | まだ誰にも割り当てていない顔（**ここが作業の本体**） |
| `顔認証外` | 「顔認証外」として外した顔（減点の印を付けた顔は `他人(減点)` へ移る） |
| `他人(減点)` | 顔認証外にした顔のうち、`他人(減点)にする` の印を付けた顔（[他人(減点)にする顔を選ぶ](#他人減点にする顔を選ぶ)） |
| **人物の名前** | **その人物に割り当て済みの顔**（旧「割り当て済みを確認」） |

- 右の数字は**残っている件数**です。操作するたびに数え直します
- 人物の行には `手本 1,156 / 自動 6,245` と内訳が出ます
- **人物はドラッグで並べ替えられます。** 上に置いた人物が打鍵の `1` になります
- 上の3つは**ドラッグで動きません**（人物の並び順だけを保存します）

### 右: 顔の一覧と操作

- **絞り込みは2段**です。上の行（並び・撮影年月・鮮明さ）は**どの表示でも**出ます。
  種別・年齢の行は**人物を選んでいるときだけ**出ます
- 顔のサムネイルは**1ページ200件**。数万件あるので必ずページ単位で読みます
- **操作は顔を右クリック**します。ボタンは置いていません（下記）
- 一覧の下の1行に、**いま効く打鍵**と選択件数が出ます
- 右下のボタンで、**絞り込みに当たる顔をまとめて処理**できます（[絞り込んだ顔をまとめて処理する](#絞り込んだ顔をまとめて処理する)）

## まず覚える3つ

**① 左で「何を見るか」を選ぶ → ② 顔を選ぶ → ③ 右クリック（か打鍵）**

```
① 左の一覧で `未分類` を選ぶ
② サムネイルを選ぶ（Ctrl＋クリックで複数、Shift＋クリックで範囲、Ctrl+A で全部）
③ 選んだ顔の上で右クリック
      ┌─────────────────────────┐
      │ 人物に割り当て                      ▸ │ → 1 ${PERSON_3}（11歳）
      │ ─────────────────────── │   2 ${PERSON_4}（7歳）
      │ 顔認証外にする…            X │   3 ${PERSON_2}（41歳）
      │ ─────────────────────── │
      │ 前のページ                 Ctrl+Left │
      │ 次のページ                Ctrl+Right │
      └─────────────────────────┘
```

**なぜボタンをやめたのか。** 見ている表示によって意味のある操作が変わるため、
ボタンを並べると**表示の数だけ増えて、押せないボタンが画面に残る**ことになります。
メニューなら、**いまできることだけ**が出ます。

**メニューには打鍵も書いてあります。** 使いながら覚えられるようにしてあります。

## 打鍵の一覧

**顔の一覧に焦点があるときだけ効きます。** 年齢の入力欄に数字を打ったときに
割り当てが走っては困るためです（顔をクリックすれば焦点が移ります）。

| 打鍵 | 操作 | どの表示で |
|---|---|---|
| `1`〜`9` | **その番号の人物に割り当て** | すべて |
| `C` | 手本に確定（自動割り当てを選んでいるときだけ） | 人物 |
| `U` | 未分類に戻す／割り当てを解除 | 顔認証外・他人(減点)・人物 |
| `N` | この人物ではない ▸ 未分類へ | 人物 |
| `X` | 顔認証外にする（人物では この人物ではない ▸ 顔認証外へ） | 未分類・人物 |
| `G` | 年齢を設定 | 人物 |
| `Z` | 「この人物ではない」を取り消す | 人物（種別が「この人物ではない」） |
| `P` / `Shift+P` | 他人(減点)にする／顔認証外に戻す（人物では `P` が この人物ではない ▸ 他人(減点)へ） | 未分類・顔認証外・人物（`P`）・他人(減点)（`Shift+P`） |
| `Ctrl+→` / `Ctrl+←` | 次／前のページ | すべて |
| `Ctrl+Z` | **直前の顔の操作を元に戻す**（下の「元に戻す・やり直す」） | すべて（顔の一覧に焦点が無くても効きます） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 元に戻した操作をやり直す | すべて |
| 矢印キー | 選択を移動 | すべて |
| `Shift`＋矢印 | 範囲で選ぶ | すべて |
| `Ctrl+A` | 全部選ぶ | すべて |

**数字は左の一覧の並び順です。** よく割り当てる人物を上へドラッグすると、
押す数字も前に来ます。**10人目からは数字が付きません**（1桁に収めるため）。
メニューからは選べます。

**人物が多くて `人物に割り当て` がウィンドウに収まらないときは、メニューがスクロールします**
（マウスのホイール、上下キー、または上下の端の矢印。#118）。メニューは GUI のウィンドウの中に出すので、
ウィンドウを大きく（最大化）しておくと一度に多く見えます。

**左の一覧は既定で狭くしてあります**（#118）。ウィンドウを広げたぶんは顔の一覧が広がります。
名前が切れるときは、左と右の境目をドラッグして広げてください。

### 元に戻す・やり直す

**顔の操作は `Ctrl+Z` で元に戻せます**（#116）。右クリックのメニューにも
`元に戻す: 3 件を 父 に登録しました` のように、何が戻るのかを名前つきで出します。
戻しすぎたら `Ctrl+Shift+Z`（または `Ctrl+Y`）でやり直せます。

- **戻せる操作**: 人物への割り当て・手本に確定・未分類に戻す／割り当てを解除・この人物ではない（行き先つきも）・
  顔認証外にする・他人(減点)にする／顔認証外に戻す・年齢を設定・「この人物ではない」を取り消す・
  右下のまとめ処理。**まとめて選んだ操作は、1回でまとめて戻ります**
- **戻せない操作**: 人物の追加・編集・削除と、自動割り当て（`match`。実行の前に控えを取れます）
- **戻せるのは直近 50 操作まで。** 履歴は GUI を開いている間だけ持ち、閉じると消えます
- **戻す前に、顔がいまも操作の直後のままかを確かめます。** そのあとで自動割り当てを流したり、人物を削除したり、
  別の画面で同じ顔を動かしたりしていると、**新しい結果を上書きしないよう戻さずに**理由を出します
  （その操作は履歴から外れ、それより前の操作は戻せます）
- **データベースに書けなかったときは、何も変えずに知らせます**（端末の `match` が書き込み中のときなど）。
  操作は履歴に残るので、しばらくしてからもう一度押せば戻ります
- 年齢などの文字の欄で `Ctrl+Z` を押すと、欄の文字の取り消しになります
- **`Z` だけ（`Ctrl` なし）は別の操作です。** 人物の種別 `この人物ではない` で、記録を取り消します（[押し間違いを戻す](#押し間違いを戻す)）

## 人物を登録する

### 追加・編集・削除

左の一覧の上のボタン、または**左の一覧を右クリック**から行えます。

| 操作 | 結果 |
|---|---|
| `人物追加` | 名前（必須）・続柄・誕生日・区分・select の重み・メモを入力して登録。**追加した人物は選ばれた状態になります** |
| `編集` | 選択中の人物を変更。名前を空にはできません |
| `削除` | 人物を消します。**割り当てた顔は消えず、未分類に戻ります** |

### 区分と select の重み

`photoarchive select` が写真を並べるときの、人物の扱いです（#110）。どちらも `select` の並びにだけ効き、
自動割り当て（`match`）には効きません。

| 項目 | 意味 |
|---|---|
| 区分 `家族` | ふつうはこちら。家族の写った写真が `select` の候補になります |
| 区分 `親しい人` | 友だち・親戚など、**家族と一緒に写っていれば加点したい人**。親しい人だけの写真は家族の写真に数えません（候補から外れます） |
| `select の重み` | 既定 1.0。大きくすると、その人がはっきり写った写真が上に来ます（その人の顔の点にかけて足します）。0 にすると点に入りません |

**追加した人物はいちばん下に入ります**（並べ替えた結果を崩さないため）。
並べ替えるまでは登録した順です。ただし**この機能より前から登録してあった人物**は
最初は名前順です。

### 誕生日を登録する（**強くおすすめ**）

誕生日を入れると、**写真の撮影日時から撮影時の年齢を機械が出します。**
年齢は、この作業でいちばん効く手がかりです。入れておくと3か所に出ます。

1. **割り当てメニューの人物名のうしろ** — `2  ${PERSON_4}（7歳）`
2. **プレビューの下** — `撮影時の年齢: ${PERSON_3} 11歳 / ${PERSON_4} 7歳`
3. **サムネイルの文字** — `(7歳)`

```
誕生日  [2011]年 [5]月 [3]日
```

- **3つとも空（`--`）なら「未設定」**です。入れなくても年齢を手で入力できます
- **3つともコンボボックスです**（#18）。年は新しい順で、**日の欄には選んだ年月に実在する日だけ**が並びます。
  欄を選んで数字を続けて打っても選べます。ホイールでは変わりません
- 月や年を変えてその日が無くなると、日は `--` に戻ります（末日に丸めません）
- **年・月・日はすべて必要です。** 一部だけだと警告が出て、**その追加・編集は行われません**
- `OK` を押した時点で、**詳細欄とメニューの年齢はすぐ変わります**

誕生日は**年齢を計算するためだけ**に使います。`Face.age` に何を入れるかを決めるのは
利用者です（機械が勝手に保存することはありません）。

## 未分類の顔を割り当てる

1. 左の一覧で `未分類` を選ぶ
2. サムネイルから顔を選ぶ（`Ctrl`／`Shift`／`Ctrl+A` で複数選択）
3. 右のプレビューで本人か確かめる
4. **右クリック → `人物に割り当て` → 人物**（または**打鍵の `1`〜`9`**）
5. 撮影時の年齢を入力する（未指定も可能）→ `OK`

**人物を左で選ぶ必要はありません。** 割り当て先はメニューが持っています。
以前は左で人物を選んでから割り当てていたので、**未分類を見ながら別の人へ振る
たびに往復が要りました。** その往復がそのまま手数でした。

### 年齢の入力

- **キーボードから直接打てます。** 入力欄は「未設定」が選ばれた状態で開くので、
  そのまま数字を打てば置き換わります。**0歳と「未設定」は別の状態**です
- **誕生日を登録していれば、計算した年齢が初期値に入ります。** そのままでよければ
  `OK` を押すだけです
- **複数の顔をまとめて選んだときは、入力した年齢が全件に入ります。** 件数と
  撮影日時の範囲がダイアログに出ます。**年の違う写真をまたいで選んでいないか**を
  確かめてください
- **選んだ顔の年齢が揃わないときは、初期値を入れません**（`未設定` で開きます）。
  片方の年齢を入れると、もう一方に間違った年齢が黙って入るためです
- **撮影日時の分からない顔が1枚でも混ざっている場合も、初期値を入れません**

### 画面が教えてくれること

**割り当てメニューに `⚠誕生前の写真あり` が出たら、人物か写真を間違えています。**
その人物が生まれる前に撮られた写真が選択に混ざっているという意味です
（`match` は誕生前には割り当てないので、**この矛盾を作れるのは手作業だけ**です）。
選べなくはしていません。1件だけ混ざった選択を丸ごと止めると、なぜ割り当てられない
のかが分からなくなるためです。

**プレビューの下に、登録した全員の撮影時の年齢が並びます。**

フォルダは写真の root からの相対です。**root が2つ以上なら root の名前が前に付きます**
（`Photo/2017/…`・`${PERSON_2}携帯/2021/…`）。設定に root が無ければ、`scan` が記録した root を使います。

```
撮影日時: 2017-12-16 18:46:32
フォルダ: 2017/171216${EVENT}
ファイル: 20171216184632.JPG
撮影時の年齢: ${PERSON_3} 10歳 / ${PERSON_4} 6歳 / ${PERSON_2} 40歳
```

未分類の作業は「この顔は誰か」を決めることなので、**全員の年齢が並んでいるほうが
効きます。** まだ生まれていない人は出しません。

写真に EXIF が無い場合は `撮影日時: 不明（EXIFなし）` と出ます。フォルダ名から
撮影時期を起こせれば `撮影時期: 2012年10月（フォルダ名から推測）` と出て、年齢も
`${PERSON_2}: 6歳?` と `?` 付きで出ます。**推測は月までです**（日付入りのフォルダ名は
行事の初日で、撮影日とは限らないため）。そのあとにファイルの日時が並びます。
**ファイルの日時は撮影日時ではありません**（コピーすると変わります）。

**登録が済むと、顔写真に重ねて `完了` と出て、写真が薄くなります。** 顔は一覧から
消えるのにプレビューには残るので、そのままだと「まだ選んでいる」ように見えて、
**同じ顔をもう一度登録してしまいます。** 次の顔を選べば元に戻ります。

**時間のかかる操作では、カーソルが砂時計になります。** 複数枚をまとめて処理する
ときは進み具合が件数で出ます（`120 / 200 件`）。**途中で止めることはできません**
（半分だけ適用された状態になるため）。

`photoarchive match` の精度は、この手作業の量と質で決まります。人物あたり
20〜50枚を目安に、正面・横向き・眼鏡の有無・年齢の違う顔を割り当ててください。

顔の切り出しや特徴量は `scan` の時点で作成済みです。**GUI が元の写真ファイルを
変更することはありません。**

## 絞り込みと並び順

### 並び順（`並び`）

| 選択肢 | 向いている作業 |
|---|---|
| **撮影日時の新しい順** | 未分類の割り当て。**同じ行事の写真が固まる**ので、まとめて選べる |
| **年齢の若い順** | 人物の見直し。**成長の順に並ぶ**ので、年齢の入れ間違いや別人の混入に気づく |
| **自動の確信度が低い順** | 自動割り当ての見直し。**誤りに早く当たる** |
| 画質の高い順 | 手本を選ぶとき（はっきり写っている顔から見たいとき） |
| **ボケている順** | ボケ・ぶれた顔を外すとき（[ボケた顔をまとめて顔認証外にする](#ボケた顔をまとめて顔認証外にする)）。顔の下に鮮明さが出る |
| **点の高い順** | 写りの良い顔から見たいとき。手本を選ぶときにも（下の「顔の点」） |
| **この人物に似た順** | **人物の未分類から本人を探す**（下の「人物に似た顔を探す」） |

**顔を操作しても、一覧のスクロールの場所は動きません**（#18）。ページ・表示・絞り込み・並びを変えると先頭に戻ります。

**どの並びにも逆向きがあります**（撮影日時の古い順・年齢の高い順・確信度の高い順・
画質の低い順・くっきりした順・点の低い順・この人物に似ていない順）。**値を持たない顔は、どちらの向きでも最後に
まとまります**（逆にしても、撮影日時の無い顔が先頭に来ることはありません）。

**顔の点**（#18）: 一覧の顔の下に、`select` が写真を選ぶときと同じ顔の点（0〜100。鮮明さ・正面・目・笑顔・大きさ・見切れ）が出ます。**重みは写真の選定タブの画面の値**で、そちらで動かしてこのタブに戻ると出し直します。`自動 55` の数字は人物らしさの確信度で、点とは別のものです。

| 表示 | 意味 |
|---|---|
| `72点` | すべての項目を測ってある |
| `約72点` | 測っていない項目があり、中間の値で計算した（未分類の顔の多くはこれです。目や笑顔は `match` や `select` が割り当てのある顔だけを測ります） |
| `点 未計測` | 鮮明さも表情も測っていない。点の順では最後に並びます |

**並べ替えは、条件に当たる全件に効きます。** いま見えている200件の中だけで
並べ替えるのではなく、**全件を並べてからページに分けて**出しています。
1ページ目には、全件の中でいちばん若い（新しい・確信度の低い…）顔が来ます。

**年齢は、画面に出ている年齢で並べます。** 確定した年齢（`7歳`）があればそれ、
無ければ誕生日と撮影日時から計算した年齢（`(7歳)`。EXIF が無ければフォルダ名から
推測した `(7歳?)`）です。年齢を出せない顔（誕生日が未登録・撮影時期が分からない）は
最後にまとまります。

**未分類・顔認証外・他人(減点)では年齢と確信度の並びを選べません。**
人物が決まっていないので年齢を出せず、確信度も持たないためです（選べても
何も変わらず、並べ替えが壊れているように見えます）。**似た順は人物を選んでいる
ときだけ**選べます（比べる人物が要るため）。理由はマウスを乗せると出ます。

**表示を切り替えると、その表示に向いた並びに戻ります**（未分類＝撮影日時順、
人物＝年齢順、人物の未分類＝似た順）。同じ表示を見ている
あいだは勝手に戻しません。

### ボケた顔をまとめて顔認証外にする

**ピンぼけ・ぶれた顔は、鮮明さで絞ってまとめて顔認証外にできます。**
絞り込みの2行目にあります。

```
□鮮明さが [━━●━━━━] [ 30 以下] （ボケ・ぶれた顔）   [鮮明さを測る] 未分類の未計測 29,098 件（絞り込みに出ません）
```

1. **はじめに `鮮明さを測る` を押します。** 未分類の顔は、鮮明さをまだ測っていません
   （手本と自動割り当ての顔は `match` と `select` が測ってあります）。サムネイルから
   測るので元写真（NFS）は読みません。**裏で流すので、測っているあいだも割り当てを
   続けられます。** 進み具合と `止める` はタブの右上に出ます。止めても、次は続きからです
2. `鮮明さが` にチェックを入れ、**ゲージか数値欄**で値を決めます。**小さいほどボケています。**
   ゲージは離したときに一覧が絞り直されます（動かしている間は数値だけが変わります）。
   ホイールは、ゲージや数値欄をクリックしてからでないと効きません（上を通っただけで値が変わらないように）。
   `select` は 30 以下を「はっきりボケている」、150 以上を「くっきり」とみています
3. 並びを `ボケている順` にすると、境目の顔（閾値に近い顔）が最後のページに来ます。
   顔の下に `鮮明さ 24` のように値が出るので、**どこで切るかを目で見て決めます**
4. 右下の `ボケた未分類（鮮明さ N 以下）をすべて顔認証外にする` を押します。
   件数を確かめる窓が出ます

- **対象は未分類の顔だけ**です。手本と自動割り当ての顔は触りません
- **鮮明さを測っていない顔は出ませんし、外しません**（ボケているか分からないため）
- 間違えたら `Ctrl+Z` で戻せます
- 鮮明さの絞り込みは、ほかの表示（人物・顔認証外など）でも効きます。人物の表示なら、
  その人物のボケた顔をまとめて未分類へ戻せます
- **測っているあいだは、まとめ処理を押せません**（一覧に出ていない顔が増えていくため）
- 鮮明さは顔を 112px にそろえて測った値なので、**小さく写った顔はボケていなくても低めに出る**
  ことがあります。境目の顔は目で見てください

### 撮影年月（`撮影 [年]年 [月]月 → [年]年 [月]月`）

**いつからいつまでに撮られた写真の顔だけ**を表示できます。**両端を含みます。**
`→` の左が古い方、右が新しい方で、それぞれ**年と月の欄**に分かれています（欄は数字だけ・指定なしは `--`・#134）。

- 月を `--` にすると、左はその年の1月から、右はその年の12月までです
- 年を `--` にすると、その側の限りが無くなります（「2015年8月以降すべて」もできます）
- **左を入れると、右にはそれ以降の年月だけが並びます。** 右が左より前になっていれば、左まで押し上げます

**家族の写っていない写真は時期でまとまっています。** 結婚式や旅行先で写った他人は
その行事の期間に固まっているので、**その月だけを開いてまとめて外せます。**

- 並ぶのは**顔のある写真の年と月だけ**で、古い順です
- EXIF に日時の無い写真も、**フォルダ名から推測した撮影時期がまるごと範囲に入れば**
  出ます（`2012/1210/` の写真は 2012-10 を含む範囲で出ます。`2012/その他/` のように
  年までしか分からない写真は、2012年をまるごと含む範囲のときだけ出ます）
- `撮影日時なしのみ` にチェックを入れると、**EXIF に日時の無い写真と、カメラが
  壊れた日時を書いた写真**がまとまって出ます（フォルダ名から撮影時期を推測できた
  写真も入ります）。**範囲とは併用できません**。該当が1件も無ければ出てきません
- **この絞り込みはどの表示でも効きます。** 「2018年の${PERSON_4}だけ見直す」も
  「この月の自動割当だけ見る」もできます

## 絞り込んだ顔をまとめて処理する

**いまの絞り込みに当たる顔を、ページをまたいでまとめて処理できます。** 右下のボタンです。
結婚式や旅行先のように**ほとんど他人**が写っている時期は、撮影年月で絞ってまとめて外せます。

| 見ている表示 | 右下のボタン |
|---|---|
| 未分類 | `絞り込んだ未分類をすべて顔認証外にする`（手本は触りません）。鮮明さで絞っていれば `ボケた未分類（鮮明さ N 以下）をすべて顔認証外にする`（[ボケた顔をまとめて顔認証外にする](#ボケた顔をまとめて顔認証外にする)） |
| 顔認証外 | `絞り込んだ顔認証外をすべて取り消す` |
| 他人(減点) | `絞り込んだ他人(減点)をすべて顔認証外に戻す`（顔認証外のまま残ります） |
| 人物 | `絞り込んだ〈人物〉の割り当てをすべて解除` |

- **何かで絞っているときだけ押せます**（撮影年月・撮影日時なしのみ・鮮明さ。人物なら年齢も）。
  絞らずに押せると、一度の押し間違いでその表示の顔が全部動いてしまうためです
- **裏で処理を流しているあいだは押せません。** 終わってから押してください
- 押すと、件数を確かめる窓が出ます。間違えたら `Ctrl+Z` で戻せます

> 使われていなかったので外しました（2026-11-03・#135）。

## 割り当て済みを見直す（人物の表示）

**左の一覧でその人物を選ぶだけです**（以前は `割り当て済みを確認` で別ウィンドウが
開きました）。人物を選ぶと、絞り込みの2段目が出ます。

```
種別[すべて ▼]  年齢[ 3 ]歳から[ 7 ]歳  □年齢不明も含める
```

### 種別

| 種別 | 出るもの |
|---|---|
| すべて | 手本と自動割り当ての両方 |
| 確定済みのみ | **手本だけ**（`match` の根拠になっている顔） |
| 自動のみ | **自動割り当てだけ**（見直しはここ） |
| **未分類** | **この人物の候補になりうる未分類の顔**（下の「人物に似た顔を探す」） |
| この人物ではない | 「この人物ではない」と記録した顔（**取り消すための一覧**） |

### 人物に似た顔を探す（種別 `未分類`）

```
左で「${PERSON_4}」を選ぶ → 種別を「未分類」にする
  → 未分類の顔が、${PERSON_4}の手本に似た順に並ぶ
  → 1ページ目を見て、本人だけ選んで 1〜9 で割り当てる
```

- **誕生前の写真と、「この人物ではない」と記録した顔は出ません**（候補になりえない）
- 並びは**その人物の手本との距離**です。**整列できなかった手本は使いません**
  （割り当てたばかりの手本は、並べる前に見え方を測ります）
- **年齢の範囲も効きます**（その人物がその年齢だった時期の写真に絞られます）。
  年上の顔を探すときは下限を上げると早い。撮影日時の無い顔は `年齢不明も含める` で戻ります
- **割り当てた顔はすぐ手本になり、次の並びに効きます。** 年上の顔を数枚割り当てると、
  似た年上の顔が上がってきます
- 初回は数秒かかります（実データで約2〜4秒・進み具合が出ます）。ページ送りでは
  計算し直しません
- 違う顔は `この人物ではない`（その人物の候補から消える）か
  `顔認証外にする…`（どの人物にも付かなくなる）で外します
- 手本が1件も無い人物では、ページの表示に「似た順に並べられません」と出ます
- **ページの後ろへ行くほど、手や物・横倒しの顔が混ざります。** 本人らしい顔が
  見えなくなったら、そこで切り上げてかまいません

### 年齢

**画面に出ている年齢と同じものを見ます。** `Face.age`（確定値）が入っていれば
その値で、入っていなければ**誕生日と撮影日時から計算した年齢**で絞ります。
`match` は年齢を書かないので、**この計算が無いと自動割り当ての顔は1件も年齢で
絞れません。** EXIF の無い写真は、フォルダ名から推測した撮影時期（`(7歳?)`）で
絞ります。推測した月がちょうど誕生月なら年齢が決まらないので「年齢不明」の側です。

- **`0` は 0歳の意味です。**「指定なし」は `0` の1つ下（`--`）にあります
- **`年齢不明も含める` は既定で入っていません。** 「7〜9歳」と指定したときに、
  年齢の分からない顔が混ざらないようにしています

### サムネイルの文字

| 表示 | 意味 |
|---|---|
| `7歳` | `年齢を設定` で入れた値。**人が確かめた年齢** |
| `(7歳)` | **誕生日と撮影日時から計算した年齢**（括弧つき） |
| `(7歳?)` | **EXIF が無く、フォルダ名から推測した撮影時期（月まで）で計算した年齢** |
| `(誕生前)` | **撮影日がその人の誕生日より前。ほぼ確実に誤りです** |
| `(自動 82)` | 自動割り当ての確信度。**低いほど怪しい** |
| （何も出ない） | 誕生日が未登録か、撮影時期が分からない（推測した月がちょうど誕生月のときも出ません） |

**確信度には下限があり、0 にはなりません**（既定の閾値 0.45 では 55.0）。
閾値より遠い顔はそもそも割り当てられないためです。

### 右クリックでできること

| 操作 | 打鍵 | 意味 |
|---|---|---|
| `手本に確定` | `C` | 自動割り当てを**手本に昇格**する。次の `match` の根拠に加わる |
| `割り当てを解除` | `U` | 未分類に戻す。**判断は残りません** |
| **`この人物ではない` ▸ `未分類へ`** | `N` | **その人物ではない**と記録して未分類に戻す。**ほかの人物には付きえます** |
| `この人物ではない` ▸ `顔認証外へ` | `X` | その人物ではないと記録して、顔認証外にする（家族の誰でもない）。**どの人物にも付かなくなります** |
| `この人物ではない` ▸ `他人(減点)へ` | `P` | 顔認証外へと同じうえに、写った写真を `select` で後ろへ回す（[他人(減点)にする顔を選ぶ](#他人減点にする顔を選ぶ)） |
| `年齢を設定…` | `G` | 撮影時の年齢を後から入れる。`未設定` に戻すこともできます |
| `別の人物に割り当て` ▸ | `1`〜`9` | **別人に付いていた顔を、解除せずに付け替えます** |

**`手本に確定` は、自動割り当てを選んでいるときだけ押せます。** すでに手本の顔に
押しても意味のある変化が起きないためです（押せない理由はマウスを乗せると出ます）。

**`この人物ではない` は行き先を選ぶ小さなメニューです**（#113）。どの行き先でも「この人物ではない」と記録します。
人物を選んで種別を `未分類` にしているときは、1つ目が `未分類のまま` になります。

**中身を見てから確定してください。** 確定した顔は `match` の判断の根拠になるので、
**間違ったまま確定すると、次回以降その誤りが根拠になって広がります。**
実データで測れた誤り2件は、どちらも**手本の問題**でした（2026-10-06）。

### 「違う」と思った顔は、解除ではなく `この人物ではない`

**「違う」の付け方は2種類あります。混ぜると取り返しがつきません。**

| 操作 | 意味 | ほかの人物には |
|---|---|---|
| `この人物ではない` | **その人物ではない** | **自動で付きえます** |
| `この人物ではない` ▸ `顔認証外へ` / `顔認証外にする` | 家族の誰でもない | 付きません |

**`割り当てを解除` では判断が残りません。** `photoarchive match` は手本と閾値だけで
結果を決めるので、未分類に戻しただけだと**流すたびに同じ顔が同じ人物に戻ります。**
実際、${PERSON_4}の自動割り当てを見直して解除した **1,785 件**がこの状態でした
（2026-10-08）。

**兄弟の赤ん坊の顔は互いによく似ています。** 「${PERSON_4}ではないが、弟かもしれない」顔には
`この人物ではない` を使ってください。`顔認証外` にすると、弟にも付かなくなります。

### 押し間違いを戻す

**直前の操作なら `Ctrl+Z` がいちばん早いです**（[元に戻す・やり直す](#元に戻すやり直す)）。
GUI を閉じたあとや、ずっと前に記録した顔は、次の手順で戻します。

種別を `この人物ではない` にすると、記録した顔が一覧できます。選んで
**`「この人物ではない」を取り消す`（`Z`）** で戻せます。

- **この一覧も撮影年月・鮮明さ・ページャが効きます**
- `顔認証外` にした顔は、この一覧から消えます（顔認証外にした顔はどの人物にも
  付かないので、記録がもう効いていないためです）。**記録自体は残っている**ので、
  あとで顔認証外を取り消すと、また一覧に戻ります

## 顔認証外の表示

「顔認証外」として外した顔が並びます。**未分類に戻せます**（`U`）。

間違えて顔認証外にした顔や、判断を保留したい顔を戻すために使います。**顔認証外にした顔は
人物の表示には出てきません**（人物を持っていないため）。この表示が唯一の戻り道です
（減点の印を付けた顔は `他人(減点)` に移っているので、そちらで `U`）。

### 他人(減点)にする顔を選ぶ

**写真に入ってほしくない人の顔**は、顔認証外にしたうえで右クリックの `他人(減点)にする`（`P`）で印を付けます（#110）。
その顔が家族と同じくらい大きく写った写真ほど、`select` で後ろへ回ります。
やめるときは `顔認証外に戻す`（`Shift+P`）。

**印を付けた顔は顔認証外から消え、左の `他人(減点)`（顔認証外の下）へ移ります**（#113）。印を付けた顔だけを
そこで見直せます（一覧には `[減点]` と出ます）。他人(減点)で `顔認証外に戻す` を押した顔は、顔認証外へ戻ります。

- **印の無い顔認証外の顔と、未分類の顔は点に入りません**（加点も減点もしない）。通りすがりの人や写してよい人まで減らさないためです
- 未分類に戻したり人物に割り当てたりすると、印は消えます

## 自動紐づけとの関係

GUI で顔を割り当てたあと、`match`（自動割り当て）を流すと、割り当て済みの顔を
手本にして残りの顔が自動で紐づきます。

### GUI から流す（おすすめ）

**メニューの `顔の割り当て` ▸ `自動割り当て（match）…` を選びます。** 端末は要りません。

```
手本 10,696 件をもとに、未分類と自動割当の顔を付け直します。
いまの自動割当 15,467 件は、いったん外してから付け直します。

変わらないもの: 手本（手動の割り当て）・顔認証外・「この人物ではない」・年齢
…
☑ 実行する前に控えを取る（photoarchive.db.bak-<日時>・約 495MB）
                                          [ 実行 ] [ やめる ]
```

1. 確認の内容を読む（**既定のボタンは `やめる`** です。Enter の連打で走りません）
2. **控えを取るかを選ぶ**（既定は取る）
3. `実行` を押す → **進み具合が件数で出ます**（実データで約30秒）
4. 終わると、**割り当てた件数と人物ごとの内訳**、控えの場所が出ます。
   左の一覧の件数もその場で変わります

**1人だけ付け直す**（#123）: 左で人物を選んでからメニューを選ぶと、確認の窓に
`全員を付け直す` / `<人物> だけを付け直す` の選択が出ます（**既定はその人物だけ**・#18。人物を選んでいなければ選択は出ず全員です）。
人物だけを選ぶと、

- 外して付け直すのは**その人物の自動割当だけ**です
- 付くのは、**いちばん近いのがその人物だった未分類の顔だけ**です。
  ほかの人物に近い顔は未分類のまま残り、結果にその件数が出ます
- **ほかの人物の自動割当は外さず、見直しもしません。** 全員で流した結果とは
  違うことがあります
- 判定には全員の手本を使います（似た別人に流れないようにするため）

手本を足した人物だけを見直したいときに使います。端末では
`photoarchive match --person "人物名"` です。

**控えは取っておくのがおすすめです。** `match` は自動割り当てを付け直すので、
控えがあれば**流す前の状態へ戻せます**し、何が変わったかも後から確かめられます。
DB と同じ大きさのファイルが DB の隣にできるので、空き容量を確かめてください。
**途中で止めることはできません**（半分だけ付け直した状態になるため）。

### 端末から流す

```bash
photoarchive match
```

`--dry-run`（書き込まずに件数だけ見る）や閾値の指定は端末からだけできます。

- 手本になるのは**手動で割り当てた顔だけ**です。自動で割り当てられた顔は、
  **`手本に確定`（`C`）しない限り手本になりません**
- `match` は実行のたびに自動割り当てを付け直します。**手動の割り当てには影響
  しません**
- **`割り当てを解除` だけでは、同じ誤りが戻ります。** 判断を残すには
  `この人物ではない` を使ってください

### 自動割り当てを取り消す

自動紐づけの結果が信用できなかったときは、まとめて取り消せます。**メニューの `顔の割り当て` ▸ `自動割り当てを取り消す（unassign-auto）…`** を選びます（#132）。

1. 確認の窓に**消える件数**が出ます（**既定のボタンは `やめる`** です）。左で人物を選んでいれば、`全員` か `その人物だけ` かを選べます（既定は全員）
2. **控えを取るかを選びます**（既定は取る。DB の隣に DB と同じ大きさのファイルができます）
3. `実行` を押すと未分類に戻り、左の一覧の件数もその場で変わります

**手動で割り当てた顔（手本）・顔認証外にした顔・「この人物ではない」・設定した年齢には触りません。** 手本を直してから自動割り当てを流せば付け直せます。

端末なら次のとおりです。

```bash
photoarchive unassign-auto --person "人物名"   # 1人ぶん
photoarchive unassign-auto                   # 全員ぶん
```

### 精度を測る

手本を増やしたり直したりしたあとに、自動割り当てがどれくらい当たるかを測れます。**メニューの `顔の割り当て` ▸ `精度を測る（evaluate）…`** を選びます（#132）。

1. 必要なら `試す閾値`（カンマ区切り）・`マージン`・`同じ写真に写る同一人物の顔も手本に残す` を変えます。既定は `photoarchive evaluate` と同じです
2. `測る` を押すと裏で流れ始めます（手本 16,720 件で約 46 秒・2026-11-04）。そのあいだも顔の割り当てを続けられます。**窓を閉じても止まりません**
3. 閾値ごと・人物ごとの**正解・取りこぼし・誤り**の表と、誤った顔の番号と場所が窓に出ます

**データベースには書きません。** 途中で止めたときは、途中の数字は出しません。表の読み方は README の「紐づけの精度を測る」にあります。

## 終了

ウィンドウを閉じると終了します。**保存は操作のたびに済んでいます**
（保存ボタンはありません）。

## 写真の選定タブ（select の調整）

`photoarchive select` が選ぶ写真を、重みを動かしながら確かめるタブです（#104）。

1. タブを開くと、左に設定と**年ごとの表**が出ます。**最初から枚数を入れられます**（#113）
2. 左で設定を変えます。初期値は `config/rule.yml` から読みます
   - **並びの重み**（#139）: 点は「家族の顔ごとの点の和 − 他人(減点)の顔の点」と「写真全体の点」を**比重**で合わせたものです
     - **比重**: 顔の側の割合（0〜100）。残りが写真全体。顔の写りを重く見るなら上げ、写真そのものの出来を重く見るなら下げます
     - **顔**: 鮮明さ・正面・目・笑顔・大きさ（その写真でいちばん大きい顔と比べて）・見切れていない。**6つの中での比**で、顔1つの点（0〜100）を作ります
     - **2人目以降の効き**: 家族を点の高い順に足すとき、2人目にこの値、3人目にその2乗をかけます。**1人だけの写真を増やしたいときは、まずこれを下げます**（既定 0.5。同じ人物の顔が複数あれば、いちばん良い顔だけを足します）
     - **他人(減点)の顔の点にかける重み**: 顔認証外にした顔のうち印を付けた顔を、家族と同じ6項目で点にして引きます。1 なら同じ写りの家族（1人目）のぶんを打ち消します
     - **写真全体**: 画質・美しさ・白飛びしていない・黒つぶれしていない（#106。`photoarchive assess` で測った写真にだけ効きます）。**4つの中での比**です
     - **画質は MUSIQ（ぶれ・ピンぼけ・暗さ）、美しさは NIMA（構図）**の値です。2つは別々の重みで、両方とも点に入ります。**どちらに寄せるかは、2つの重みの比**で決まります（既定は画質 0.3・美しさ 0.1 で、画質寄り）
   - 各項目は**横ゲージ・入力欄・`既定` ボタン**の1行です（#120）。ゲージを左右に動かすと入力欄の値が刻み（0.05 か 1）で動きます。細かい値やゲージの右端より大きい値は、入力欄に直接入れてください（そのまま使います。ゲージは右端に止まります）。**`既定` を押すと、その項目だけが既定値に戻ります**（既定のままなら押せません。マウスを載せると既定値が出ます）。**設定欄ではホイールで値は変わりません**（#18。ゲージや入力欄の上でも、クリックしたあとでも、ホイールは設定欄のスクロールになります。年ごとの枚数の表の上では、まず表の中がスクロールします）。値はゲージのドラッグ・打鍵・上下キー・欄の矢印で変えます
   - **撮影時期**（#134）: `始め`・`終わり`を**年・月・日のコンボボックス**で選びます（#18）。年だけ・年月までも指定でき、始めは初日から、終わりは末日までになります。**年が `--` なら絞り込みません。** 変えると年の表が作り直されます。**表から消えた行の枚数も残ります**（期間を戻すと出てきて、そのまま保存してもファイルから消えません）。読めない値や、始めが終わりより後の値では「選ぶ」と「ルールを保存」が止まります
   - **絞り込み**・**似た写真の判定**
   - **年ごとの枚数**: 年ごとに「選ぶ枚数」を入れます。0 の年からは選びません。`全部の年に入れる` で同じ数を一度に入れられます
     - **年不明**: 撮影した年の分からない写真（撮影日時が壊れていて、フォルダ名からも年が読めない）の枚数。撮影時期を入れていると、年の分からない写真は外れるので候補は 0 枚です
     - **〇〇年以降**: 候補のある最後の年より後の写真の枚数（これから増える年のため）。**撮影時期の終わりがその年より前なら、この行は出ません**（#134）
     - **ルールに書いていない年の行は枚数 0 で出て、そのままでは選びません。年が変わったら、ここを設定し直してください**（新しい年の行が表に並びます）
   - **出力の形**: 年ごとのフォルダか、出力先の直下か（#134）。選ぶ写真は変わらないので、「選ぶ」を押し直さなくても「出力する」に効きます
3. **「選ぶ」**を押します（約1秒。値を変えただけでは選び直しません）。**初回と、顔の割り当てを変えたあとは、先に家族の顔の写り方を読み直します**（まだ測っていない顔があれば測るので、初回は数分かかることがあります）
4. 右の **`並び`** で一覧の順を変えられます（#18。年の古い順＝既定・撮影日時の新しい順／古い順・点の高い順／低い順。点の順では顔の下に点が出ます。**見せ方だけで、選ぶ写真と出力は変わりません**）。右の `撮影` で**年・月**を選ぶと（欄の働きは顔の割り当てタブと同じ・#134）、その範囲に選んだ写真がサムネイルで並びます（年不明の写真は範囲と関係なく、`年不明を入れる` で決めます。既定は入れて最後に並びます（点の順では点のとおりに混ざります）。**表示だけの絞り込みで、選ぶ写真と出力は変わりません**）。**写真を選ぶと、右に大きく出て、その下に点の内訳**が出ます（#113）（なぜその順位かが分かります）。内訳の下には `assess` で測った値（画質・美しさ・白飛び・黒つぶれ）も出ます。重みが 0 でも出るので、重みを決める手がかりにしてください
5. 気に入ったら**メニューの `写真の選定` → `ルールを保存`** で、いま読み込んでいるファイルに上書きします（最初は設定の `rule_path`。`ルールのファイル:` の行に出ます）。もとのファイルは `rule.yml.bak` のように控えます（**ファイル内のコメントは消えます**）。同じメニューの **`別のファイルに保存…`** は保存先を選んで書き、**`ルールを読み込む…`** は選んだファイルの内容で画面の設定を置き換えます（#18。読めないファイルなら画面は変わりません）。どちらも、以後の「ルールを保存」の上書き先がそのファイルになり、**設定の `rule_path` もそのファイルに書き換わります。次に起動したときも、CLI の `select` も、そのファイルを読みます**（設定ファイルは `app_settings.yml.bak` に控えます。設定ファイルのコメントは消えます。設定に書けないときは知らせるだけで、読み込みと保存は行われます）。このメニューは写真の選定タブのときだけ押せます
6. **「出力する」**で出力先にコピーします（`photoarchive select` と同じ。前の出力は消えます）。形は `出力の形` の欄のとおりで（既定は年ごとのフォルダ）、確認の窓にどちらで出すかが出ます

**顔の割り当てを1枚目のタブで変えたら、もう一度「選ぶ」を押してください。** 変わったことを見て読み直します。選んだあとに割り当てを変えて「出力する」を押すと、古い結果は出力せずに選び直しを求めます。

## 取り込みウィザード

新しく撮った写真を取り込むウィザードです。**メニューの `取り込み` ▸ `取り込みウィザード…`** で開き、`次へ` で進みます（#129・#130・#132）。どの段も**裏で流す**ので、そのあいだも顔の割り当てを続けられます。**同時に流せるのは1つだけ**で、流しているあいだは `次へ`・ほかの裏の処理・自動割り当て（match）を押せません。

| 段 | 内容 | 端末なら |
|---|---|---|
| 1 | root（写真の置き場）を確かめる | |
| 2 | `HEIC を JPEG に変換する`（要らなければ `次へ` で飛ばす） | `photoarchive convert-heic` |
| 3 | `スキャンを始める` | `photoarchive scan` |
| 4 | 次にやること（顔の割り当て → 自動割り当て → 写真の良し悪し → 選定）の案内 | |

root は設定（`config/app_settings.yml` の `source_roots`）から取ります。設定に無ければ、前に走査した root を使います。

**窓を閉じても裏の処理は止まりません。** 進み具合はタブの右上に出続け、終わると主窓のいちばん下（ステータスバー）に1行出ます。開き直すと同じ段に戻ります。`完了` を押すと、次は最初の段からです。

### HEIC を JPEG に変換する

iPhone の写真（HEIC/HEIF）は、スキャンの前に JPEG にします（スキャンは HEIC を読みません）。**「HEIC を JPEG に変換する」**を押し、確認の窓で「はい」を選ぶと裏で流れ始めます。

- 同じフォルダに JPEG を書きます。元の HEIC は残します。変換済みの写真は飛ばします
- **読めない HEIC（壊れている）は飛ばして**、下の欄に出します。端末の `convert-heic` のように1件ずつは聞きません
- **JPEG が書けなければ、そこで止めて知らせます**（書き込み権限が無い・空き容量が無い、など。続けても書けないため）。それまでに変換した JPEG は残ります
- 終わったら、`次へ` でスキャンへ進んでください

### スキャンする

1. 必要ならワーカー数を変えます（既定は CLI と同じ）。「消えたファイルの行を DB から消す」は普段は入れたままにします（最後まで走査したときだけ消します。2割を超えて消えていれば、未マウントを疑って中断します）
2. **「スキャンを始める」**を押します。確認の窓で「はい」を選ぶと、裏で流れ始めます
3. **流しているあいだも、1枚目のタブで顔の割り当てを続けられます。** 進み具合はタブの右上と窓の中に出ます。**自動割り当て（match）だけは、終わるまで押せません**
4. 終わると、件数が窓の下の欄に出て、顔の一覧が読み直されます。読めなかったファイルもここに出ます（詳しくは `data/logs/scan_*.log`）

### 写真の良し悪しを測る

**メニューの `取り込み` ▸ `写真の良し悪しを測る（assess）…`** で開く別の窓です（ウィザードの外にあるのは、取り込みの直後には新しい写真が対象にならないためです）。家族の写った写真の**画質（MUSIQ）・美しさ（NIMA）・白飛び・黒つぶれ**を測ります。写真の選定タブの点に使います。**顔を割り当てて自動割り当て（match）を流したあと**に押してください（家族の写った写真だけを測るため）。

- ボタンの横に**まだ測っていない家族の写真の枚数**が出ます。0 枚ならボタンは押せません
- **元写真を NFS から読むので、初回は一晩かかることがあります。** 2回目からは、まだ測っていない写真だけを測ります
- **モデル（`models/` の ONNX）が無ければ、始める前に置き方を出します**（README の「写真の良し悪しのモデルの書き出し」）
- 見つからなかった写真（NFS が外れていた）は記録しません。マウントし直して、もう一度押せば測ります

### 途中で止めるとき

タブの右上か窓の中の **「止める」** を押します。書きかけを保存し、処理中の数件が終わるのを待ってから止まります。**済んだぶんは保存されていて、次に同じボタンを押すと続きからになります。** **`evaluate` だけは例外です**（何も保存しないので、途中の結果は出さず、測り直すときは最初からです）。 スキャンを止めたときは、消えたファイルの行は消しません。

**流したまま主窓を閉じようとすると**、「止めて閉じますか」と聞きます。「はい」なら止まるのを待ってから閉じます。

**「書き込めませんでした」と出たら**: 裏のスキャンや、端末で流している `photoarchive` がデータベースを使っていて、30 秒待っても書けなかったときです。その操作では何も変わっていないので、少し待ってからもう一度やり直してください。

**GUI で使えない指定**: `--force-rescan`（手動割り当てと顔認証外が消えます）・`--force-prune`・`--allow-missing-embeddings` は、端末の `photoarchive scan` で使います。`assess --limit`（動作確認用）も端末だけです。

## 設定を直す

メニューの **`設定…`** で、`config/app_settings.yml` の次の4つを見て直せます（どのタブからでも開けます）。

| 欄 | 設定のキー | 保存したら |
|---|---|---|
| DB の場所 | `database_path` | **次に起動したときから**使います（開いている DB はそのまま） |
| 写真の置き場所（root） | `source_roots` | すぐ取り込みウィザードと assess の窓の一覧に出ます。`追加…` でフォルダを選び、`外す` で一覧から外します |
| 出力先 | `output_root` | すぐ写真の選定タブの「出力する」に効きます |

- 窓の上に、どのファイルに書くかが出ます。まだ設定ファイルが無ければ、保存したときに作ります
- **保存すると、もとのファイルを `app_settings.yml.bak` に控えます。ファイルの中のコメントは消えます。** 窓に出ていないキー（`dlib_model_dir` など）はそのまま残ります
- 次のときは保存できません
  - 写真の置き場所が入れ子になっている（`scan` と同じ）
  - **出力先が写真の置き場所と重なっている**（同じ・内側・外側）。出力先は出力のたびにファイルを消すので、写真の置き場所の外に `select` 専用のフォルダを作ってください
  - **DB の場所が空**（空にすると、次に `--db` なしで起動できなくなります）
  - 設定ファイルが壊れていて読めない（ファイルを直してから開き直してください）
- 見つからないフォルダがあると、保存してよいか聞きます（NAS が外れているだけのこともあるため）
- 写真の置き場所に相対パスを書いたときは、設定ファイルの置き場所（`config/` の1つ上）から解きます
- `--db` を付けて起動したときは、次に起動したときも `--db` が優先します

キーの詳しい意味は [CONFIG.md](CONFIG.md) にあります。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| **年齢が出ない** | 人物に**誕生日**が登録されているか（左下の詳細欄）。写真に撮影日時があるか（プレビューの下） |
| **右クリックしても操作が少ない** | **その表示でできることだけ**が出ます。たとえば未分類には「未分類に戻す」はありません（戻す先が無いため） |
| **打鍵が効かない** | **顔の一覧に焦点がありますか。** 顔をクリックしてから打ってください |
| **`手本に確定` が灰色** | **自動割り当ての顔を選んでいますか。** 手本に押しても変化が起きないため押せません |
| **まとめて処理のボタンが押せない** | **何かで絞っていますか**（撮影年月・撮影日時なしのみ・鮮明さ・人物なら年齢）。絞らずに押せると、一度の押し間違いで全部に効いてしまいます。**裏で処理を流しているあいだも押せません** |
| **人物を並べ替えたのに数字が変わらない** | 並べ替えは離した時点で保存されます。数字は**左の一覧の上から**順です |
| **絞ったのに0件** | 撮影年月と種別と年齢が重なっていませんか。`撮影日時なしのみ` は「EXIF の無い写真だけ」を見る別の指示なので、範囲と併用できません |
| **同じ顔をまた登録してしまう** | プレビューに `完了` の帯が出ているあいだは、**その顔はもう処理済み**です |
