# GUI利用手順

PhotoArchiveAIのGUIでは、人物情報の管理と、人物照合に使用する顔画像の登録を行えます。

## 起動前の準備

GUIを起動する前に、次を完了してください。

1. UbuntuのGUI関連ライブラリをインストールする
2. Python依存ライブラリをインストールする
3. SQLiteデータベースを初期化する
4. 必要に応じて `photoarchive scan` と `photoarchive analyze` を実行する

インストール方法は [README.md](../README.md#インストール) を参照してください。

GUIはX11またはWaylandの表示セッションが必要です。SSHなどのリモート環境から起動する場合は、X11転送やWaylandの接続設定も必要になります。

## 起動

仮想環境を有効にして、データベースを指定します。

```bash
source .venv/bin/activate
photoarchive-gui --db data/photoarchive.db
```

別のデータベースを使う場合は、そのパスを `--db` に指定します。

```bash
photoarchive-gui --db /path/to/photoarchive.db
```

## 画面構成

メイン画面には次の部品があります。

- `人物追加`: 新しい人物を登録
- `編集`: 選択中の人物情報を変更
- `削除`: 選択中の人物と、その人物に登録した顔画像を削除
- `顔画像登録`: 選択中の人物に顔画像を登録
- 人物一覧: 登録済み人物を表示
- 人物詳細: 名前、続柄、メモ、登録顔数を表示

## 人物を追加する

1. `人物追加` を押す
2. 名前を入力する
3. 必要に応じて続柄とメモを入力する
4. `OK` を押す

名前は必須です。名前が空の場合は登録できません。

## 人物情報を編集する

1. 人物一覧から対象の人物を選択する
2. `編集` を押す
3. 名前、続柄、メモを変更する
4. `OK` を押す

名前を空にすることはできません。

## 顔画像を登録する

1. 人物一覧から登録先の人物を選択する
2. `顔画像登録` を押す
3. 顔が写っている画像を選択する
4. 検出された顔の候補を確認する
5. 登録する顔の `選択` ボタンを押す

対応する画像形式はJPEG、PNG、BMP、HEIC、HEIFです。画像から顔を検出できない場合や、顔埋め込みを生成できない場合は登録できません。

登録した顔画像は人物照合用の埋め込みとしてSQLiteデータベースに保存されます。元の画像ファイルは変更されません。

同じ人物について、正面、横向き、眼鏡の有無など異なる顔画像を複数登録すると、照合の精度向上が期待できます。

## 人物を削除する

1. 人物一覧から対象の人物を選択する
2. `削除` を押す
3. 確認ダイアログで `Yes` を押す

人物を削除すると、その人物に登録した顔画像も削除されます。この操作は元の写真ファイルには影響しません。

## 解析との関係

GUIで人物と顔画像を登録した後、`photoarchive analyze` を実行すると、登録済み顔画像との照合に使用されます。

```bash
photoarchive analyze
```

顔検出や顔ランドマーク処理はGUIの顔画像登録時にも実行されます。顔を検出できない場合は、より大きく顔が写った、明るく鮮明な画像を使用してください。

## 終了

ウィンドウを閉じるとGUIを終了できます。
